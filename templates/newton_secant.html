Metode Newton-Raphson & Secant

Perbandingan dua metode terbuka untuk mencari akar fungsi non-linier transenden.

Reset Default

Fungsi Utama:

f(x) = x² + e⁻²ˣ · sin(x)

Turunan Pertama f'(x) untuk Newton:

f'(x) = 2x - 2e⁻²ˣ·sin(x) + e⁻²ˣ·cos(x)
Bagian 1: Metode Newton-Raphson
1 Titik Tebakan Awal
Rumus Iterasi Newton-Raphson: x_{i+1} = xᵢ - [ f(xᵢ) / f'(xᵢ) ]
Berhenti jika |x_{i+1} - xᵢ| ≤ Toleransi atau |f(xᵢ)| ≤ 10⁻⁶.

Bagian 2: Metode Secant
2 Titik Tebakan Awal
Rumus Iterasi Secant: x_{r+1} = x_r - [ f(x_r) · (x_r - x_{r-1}) ] / [ f(x_r) - f(x_{r-1}) ]
Berhenti jika |x_{r+1} - x_r| ≤ Toleransi atau |f(x_r)| ≤ 10⁻⁶.
